# TheSummitPyQuiz
A console-based Python coding quiz designed to test and develop programming knowledge through challenge, persistence and continuous improvement. The project features multiple difficulty levels, score tracking, lives, input validation, match-case statements, coding-related questions and more. Created as part of my software development journey...

Features
Easy, Medium and Hard difficulties
Score tracking system
Lives system
Restart functionality
Input validation
Multiple Choice Questions (MCQs)
Free Response Questions
Dictionary-based question storage
Separate modules for each difficulty

Files
mainQuiz.py - Main quiz program
easy.py - Easy difficulty questions
medium.py - Medium difficulty questions
hard.py - Hard difficulty questions

Variables

Requirements
This project uses custom Python modules that must be present in the same folder as the main program.

How To Play
Run mainQuiz.py
Choose a difficulty:
Easy
Medium
Hard
Answer the questions
Earn points for correct answers
Avoid losing all your lives
Restart or quit at the end of the quiz
